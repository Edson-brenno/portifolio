O primeiro problema real

Analista de Sistemas · Prefeitura de Mata de São João

Equipes de saúde esperavam quatro meses para ter acesso a dados que deveriam guiar decisões diárias. Ali eu entendi que tecnologia é sobre pessoas. Construí pipelines ETL que reduziram essa espera para um dia.

  • Pipelines ETL automatizados com Python (Pandas, SQLAlchemy) e PostgreSQL.
  • Entrega de pipelines de 3 dias para 1 dia, com POO e arquitetura de código reutilizável.
  • Ingestão 83% mais rápida (30 → 5 min) com bulk load via io.StringIO, eliminando gargalos de I/O.

Agora

07/2024 — atual · Dias d'Ávila, BA

Arquitetar do zero

Desenvolvedor de Software Pleno · Zrn Tecnologias

Hoje sou responsável pela arquitetura e engenharia completa do ecossistema back-end — do planejamento e modelagem à segurança de bancos, orquestração em nuvem e observabilidade. Meu foco: uma Clean Architecture que permita à empresa crescer sem medo.

  • Plataforma com 9 microsserviços em Java/Spring Boot, cada um com banco e ciclo próprios.
  • API Gateway com Kong e serviço central de autenticação em Python: ponto de entrada único e seguro.
  • APIs centrais da plataforma de planejamento estratégico: planos municipais de 30+ dias para <1 dia.
  • API REST em FastAPI desacoplada do monolito — base da migração para microsserviços.
  • RabbitMQ para filas e processamento em background, liberando a aplicação principal.
  • Pipeline ETL do e-SUS orientado a eventos com Celery, em VPS Linux provisionadas por mim.
  • CI/CD, Docker e observabilidade em tempo real para detectar falhas antes do usuário.
